## 2026-10-15

### Added
- Opening hours with auto-close: the seller sets each day's times (or closed) on a new admin **Hours** tab.
  Outside them the shop says "Closed · opens …" and the Google script refuses orders. Today's hours show
  under the shop name. No hours set = open as before. 14 new tests.

## 2026-10-13

### Added
- Delivery or pickup on every shop: delivery +$1 per order (Settings `deliveryFee`), pickup free; room only asked for delivery. 2 new tests.
- Four new shops (demo mode): Henry's Bakery, Yitz's Grill, Josh's Hot Dog Stand, Eli's Kitchen — own colors, drawings, menus; QR codes for all.
- Errors use a fixed red (`--danger`) in every shop.
- MikdashMunchies home page at https://mikdashmunchies.github.io/ (a card per shop) and a README with every link — both generated by `node build.js`.
- Shared CSS/JS links are fingerprinted so visitors get updates immediately (no 10-minute stale cache).

### Changed
- "Classroom" removed from descriptions; banner now says "Delivery or pickup".
- QR maker tries other QR patterns if a code doesn't scan back.
- David's live Google script updated to version 4 (delivery fee).

## 2026-10-11 → 2026-10-12 (first session)

### Added
- Project folder, `CLAUDE.md`, this changelog, design spec and plan (`planning/`).
- Business pricing for sellers: $10 setup + $15/month.
- Google Apps Script back end (`apps-script/Code.gs`): menu from the Sheet, server-side pricing, password-protected admin actions, open/closed switch, Zelled checkboxes; 11 tests.

- **Template:** `template/` (shared core) + `shops/<slug>/shop.json` (details) + `node build.js` → `docs/`; `node build.js new <slug>`; 5 build tests incl. a stale-`docs/` check.
- Demo mode for shops with no `apiUrl` (orders shared between shop and admin pages via localStorage).
- `SETUP.md` (new-shop guide), `qr/make_qr.py` (QR maker that scans its own output), QR for David.
- **Live:** David's Google Sheet + script deployed; site published at https://mikdashmunchies.github.io/davids-paninis/ (GitHub org MikdashMunchies).
- `.gitattributes` pinning LF line endings.
