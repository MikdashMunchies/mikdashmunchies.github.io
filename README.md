## Where it stands (last worked on 2026-10-18)

- **Eli's Kitchen** is the real, live client: orders go to his Google Sheet, with Telegram and email alerts.
- The other shops are demos (no Google Sheet yet). David's Meat Paninis is not a client.
- Built: menu editing from the admin page, order form, Zelle and cash, opening hours with breaks and
  auto-close, sale prices, sold-out per item, photos and descriptions, maaser, analytics, spam brakes.
- Next: enter Eli's exact opening hours, then the next feature or a new client.

## Things I want to see

- More paying clients (each new shop takes about 25 minutes).
- Surcharge at certain times, meal deals / combo discounts.
- Food labels (meat / dairy / pareve).
- An order-time estimate with a live timer for the buyer; pickup time slots.
- Scheduled pre-orders (same day free, calendar paid).
- An order confirmation for the customer (email or text); a loyalty program.

## Getting started

- `node build.js` builds every shop page into `docs/` (and this README). GitHub Pages serves `docs/` on `main`.
- `node build.js new <shop-name>` starts a new shop; full steps in [SETUP.md](SETUP.md).
- `node --test` runs the tests.
- Order handling lives in a Google Apps Script per shop: `apps-script/Code.gs`.
- Notes for maintainers: [CLAUDE.md](CLAUDE.md).
